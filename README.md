# NewsFeedApp – Android News Reader

An Android news app built with **Kotlin** and **Jetpack Compose**. It loads top stories from [TheNewsAPI](https://www.thenewsapi.com/), filters them by category, date and unwanted words, tags article images using the [Imagga](https://imagga.com/) image-recognition API, and caches news in a local **Room** database so it can still be read offline.

> Project for the course **Razvoj mobilnih aplikacija (Mobile Application Development)**, Faculty of Electrical Engineering, University of Sarajevo. The app was built over four iterations ("spirale").

---

## Features

- **News feed** with two card types: large *featured* cards for the newest top stories and compact *standard* cards for the rest
- **Category filter chips**: All (Sve), Politics (Politika), Sport, Science/Tech (Nauka/tehnologija), Health (Zdravlje)
- **Advanced filter screen**:
  - date range picker (Material 3 `DateRangePicker`)
  - list of unwanted words that hides any article containing them in the title or snippet
- **Live data from TheNewsAPI**:
  - top stories per category, cached for 30 seconds so the API isn't called repeatedly
  - similar stories for each article
- **Article details screen** with image, snippet, category, source and date, plus:
  - **image tags** generated by the Imagga API
  - **two related articles**, which you can tap to open
- **Offline mode**: news and image tags are saved to a Room database and loaded from there when there is no internet connection
- **Instrumented UI and data tests** for every iteration (`TestS1`–`TestS4`)

## Architecture

```
UI (Compose screens)
   │
   ▼
NewsService  ──────────────►  SavedNewsDAO (Room)  ← offline cache
   │
   ├──► NewsDAO   ──► TheNewsAPI   (top stories, similar stories)
   └──► ImagaDAO  ──► Imagga API   (image tags)
```

- **`NewsService`** is the main data layer. It holds the current list of news in a `StateFlow`, merges new API results, handles category mapping (UI names ↔ API names) and caches similar stories and image tags.
- **`NewsDAO` / `ImagaDAO`** wrap the Retrofit services. They add caching, input validation (UUID and image URL checks with custom exceptions) and fallbacks when a request fails.
- **`NewsDatabase`** is a Room database with three tables: `News`, `Tags` and the junction table `NewsTags` (a many-to-many relation between articles and image tags).

### Screens and navigation

| Route | Screen | Description |
|---|---|---|
| `home` | `NewsFeedScreen` | Feed + category chips |
| `filters` | `FilterScreen` | Category, date range and unwanted-word filters |
| `details/{id}` | `NewsDetailsScreen` | Full article, image tags, related news |

Filter results are passed back to the feed through the `SavedStateHandle` of the previous back-stack entry.

## Getting started

### Requirements
- Android Studio (Ladybug or newer)
- Android device or emulator running **Android 12 (API 31)** or higher
- Free API keys from [TheNewsAPI](https://www.thenewsapi.com/) and [Imagga](https://imagga.com/)

### API keys
The app needs two sets of credentials:

| Service | Where it is used |
|---|---|
| TheNewsAPI token | `data/network/NewsDAO.kt` → `API_TOKEN` |
| Imagga API key + secret | `data/network/retrofit/RetrofitInstance.kt` → `RetrofitInstanceImaga` |

Put your own keys there before running the app.

### Run
1. Clone the repository:
   ```bash
   git clone https://github.com/ikarahodza/News-Source-Mobile-App.git
   ```
2. Open the project in Android Studio and let Gradle sync.
3. Add your API keys (see above).
4. Choose an emulator or a connected device and click **Run ▶**.

### Tests
The tests are instrumented, so they need a running emulator or device:
```bash
./gradlew connectedAndroidTest
```
